# История изменений

## Проверка на игре 1.1.1 — 2026-11-19

Версия 0.4.5 сохранена; код и файлы выпуска не менялись. Обновлена только информация о совместимости. Проверены сборка на библиотеках 1.1.1, загрузка 14 обработчиков событий и создание нового отзыва в игровом запуске.

При совместном использовании обновите фильтры полок до [0.10.6](https://github.com/Midfr0st/AnimeShopSimulator-ShelfFilters/releases/tag/v0.10.6). [Результаты и границы проверки](https://github.com/Midfr0st/AnimeShopSimulator-WolfCore/blob/main/docs/COMPATIBILITY-1.1.1.ru.md).

## Проверка на игре 1.0.74 — 2026-10-20

Версия 0.4.5 сохранена; код и DLL не изменились. Проверены сборка на библиотеках 1.0.74, загрузка мода и подключение 14 игровых событий.

Обновлены README и сведения в выпуске. Для совместного использования с фильтрами полок требуется [0.10.5](https://github.com/Midfr0st/AnimeShopSimulator-ShelfFilters/releases/tag/v0.10.5). [Результаты общей проверки](https://github.com/Midfr0st/AnimeShopSimulator-WolfCore/blob/main/docs/COMPATIBILITY-1.0.74.ru.md).

## 0.4.5 — 2026-10-03

Совместимость с Anime Shop Simulator 1.0.7.

- Исправлено создание страницы отзывов в Anime Shop Simulator 1.0.7 после удаления поля _levelText из игрового терминала.
- Заголовок и подзаголовок сдвинуты, чтобы освободить место для новой кнопки с домиком. Обновлены фон и акцентные цвета страницы.
- Страница использует исправленную навигацию и плитку терминала из WolfCore 0.2.6.

Сборка и короткая игровая проверка основных сценариев прошли успешно. Для модулей используйте WolfCore 0.2.6.
